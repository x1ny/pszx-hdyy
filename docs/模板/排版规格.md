# 邀请函模板排版规格

来源：业务方在三份模板 `.docx` 里以 Word 批注形式标注的排版要求。批注本身已从模板文件中移除（会跟着生成的邀请函一起显示出来），内容原样留档在这里。

带批注的原始文件保留在 `原始带批注/`。

---

## 页面

| 项 | 值 |
|---|---|
| 纸张 | A4（11906 × 16838 twips） |
| 页边距 | 上下 2.54cm，左右 3.17cm |

## 各区块

| 区块 | 规格 |
|---|---|
| **logo**（联盟版） | 2.4cm × 5.71cm，左上角对齐 |
| **红头文字**（商会版 / 专班版） | 方正小标宋简体，一号字（专班版标注为 20 号字），红色；下面两条红色的线，一粗一细，也是固定的 |
| **标题「邀请函」** | 方正小标宋简体，二号字，居中，距离 logo（或顶头）空一行，固定值 28 磅 |
| **称谓** | 仿宋，三号字，首行缩进 2 个字符，固定值 28 磅，距离「邀请函」空一格，向左对齐 |
| **正文** | 仿宋，三号字，首行缩进 2 个字符，固定值 28 磅，两端对齐 |
| **印章图**（联盟版） | 5.53cm × 15cm，底部对齐 |
| **落款** | 仿宋，三号字，固定值 28 磅，距离正文空一格，向右对齐 |
| **附件提示行** | 仿宋，三号字，固定值 28 磅，向左对齐 |
| **附件标题** | 黑体，三号字，居中对齐，固定值 28 磅 |
| **附件正文** | 仿宋，三号字，固定值 28 磅，距离标题空一格，首行缩进 2 个字符，两端对齐 |
| **附件备注** | 楷体，三号字，固定值 28 磅，首行缩进 2 个字符，两端对齐 |

> 「固定值 28 磅」= `w:line="560" w:lineRule="exact"`；
> 「首行缩进 2 个字符」= `w:firstLineChars="200"`（字符单位，会随字号自适应，不要写成绝对 twips）；
> 三号字 = 16pt（`w:sz="32"`），二号字 = 22pt（`w:sz="44"`）。

## 文档结构

三份模板结构完全一致，只有文头和落款不同：

```
文头        联盟 = logo 图 │ 商会 / 专班 = 红字抬头 + 两条红线
标题        邀请函
称谓        {{姓名}}：
正文        4 段（其中一段含 {{姓名}}）
祝颂        顺祝安康!
联系人      联系人：{{联系人}}      联系电话：{{联系电话}}
附件提示    附件：xxx
印章        图片 │（xx 局代章）
落款        右对齐
日期        右对齐
──────────── 附件页 ────────────
附件：/ 附件标题（黑体居中）/ 附件正文 / 备注（楷体）
```

## 变量约定

模板里用 `{{变量名}}` 标出要替换的位置。系统上传时自动解析，分成两类：

| 类型 | 变量 | 谁来填 |
|---|---|---|
| 系统变量 | `{{姓名}}` | 生成时按每个邀请对象自动填 |
| 系统变量 | `{{发函日期}}` | 生成时取发函日期选择器的值 |
| 自定义变量 | 其余任何 `{{xxx}}` | 每次生成时在生成页填写 |

正文内容**不做成变量**，直接写死在模板文件里——改正文就是改模板重新上传。

### 写占位符的注意事项

在 Word 里输入 `{{姓名}}` 时，输入法和拼写检查有时会把它切成好几段（XML 里表现为多个 `<w:t>`）。系统的解析器能处理这种切分，**不用特意规避**；但如果上传后解析出来的变量数量不对，多半是占位符里混进了不可见字符，重新纯文本粘贴一次即可。

## 字体：一个需要业务方确认的问题

商会模板嵌入了 4 个**子集化**字体（每个 176–270 KB；完整中文字体是 5–20 MB），只包含原文档里出现过的那些字。后果是：**替换进去的人名如果含有原文档没出现过的字，在没装对应字体的机器上可能显示不出来**。

联盟模板则完全没有嵌入字体，三份模板在这件事上口径不一致。

建议业务方另存模板时统一处理：

- Word：文件 → 选项 → 保存 → 勾选「将字体嵌入文件」，并**取消勾选**「仅嵌入文档中使用的字符」
- 或者干脆不嵌入，依赖目标机器自带的仿宋 / 黑体 / 楷体（中文 Windows 都有）

（系统的页面内预览已经绕开了这个问题——预览时不使用嵌入字体，改用同名系统字体。）
